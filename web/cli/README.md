# YDS - Altegio UI CLI

CLI для работы с компонентами Altegio UI. Позволяет создавать шаблоны компонентов Lit (core), Vue и Angular. При этом компоненты Vue и Angluar представляют собой обертки и создаются на основе Lit (core) компонентов.

## Сборка CLI
```bash
pnpm cli-build
```

## Использование CLI 

### Создание нового компонента
```bash
yds create
```

### Обновление существующего компонента
```bash
yds update
```

Команда запускает интерактивный режим обновления компонента, последовательно запрашивая необходимые параметры.

## Примеры
```bash
# Запуск интерактивного режима создания компонента
yds create
# Запуск интерактивного режима обновления компонента
yds update
```

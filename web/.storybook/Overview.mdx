# Altegio UI · Beta

**Beta · under active development.** The public API may change before 1.0.

Install with `npm install @altegio/ui` or select the beta channel with `npm install @altegio/ui@beta`.

Explore the components, design tokens and framework integrations in Altegio’s design system.

## Component catalogs

Each catalog includes interactive examples, component states and API documentation. Choose a catalog below or browse its components in the sidebar.

- [Core · Web components](?path=/docs/core_button--docs) — use Lit-based custom elements in any web application.
- [Vue](?path=/docs/vue_button--docs) — use components through the Vue integration.
- [Angular](?path=/docs/angular_button--docs) — use components through the Angular integration.
